# Repository jobs

`frontend-performance-quality` measures, investigates and fixes Console
performance and quality issues every 14 days from November 3, 2026 at 14:00 UTC.
Sprinkles owns a separate job covering its three frontends, staggered one day
earlier. The recipe retains evidence and uses the normal protected PR path.

See [repository-owned jobs](../../docs/repository-jobs.md#fortnightly-frontend-maintenance)
for the resource contract, runtime qualification and explicit activation steps.
